# SuperDocs builds — submission staging

This directory mirrors the layout of
[`superdocsapp/superdocs-builds`](https://github.com/superdocsapp/superdocs-builds)
so the work can be dropped straight into a fork.

```
use-cases/noormdafsar/renewal-desk/
```

## To submit

1. Fork `superdocsapp/superdocs-builds`.
2. Rename `use-cases/YOUR-GITHUB-USERNAME/` to your actual GitHub username.
3. Copy that folder into your fork, commit, and open a pull request.
4. Use `PULL_REQUEST.md` as the PR body — it needs your real name, and per
   CONTRIBUTING.md it must **not** contain your email address.

Nothing outside your own folder should be modified.
